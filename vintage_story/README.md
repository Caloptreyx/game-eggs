# Vintage Story

Vintage Story is an uncompromising wilderness survival sandbox game inspired by eldritch horror themes: survive a harsh, procedurally generated world through the seasons, from stone tools to bronze, iron and steel.

Native Calagopus egg for the official Vintage Story dedicated server for Linux, downloaded from Anego Studios' CDN (Vintage Story is not on Steam). The server is a .NET application; the installer adds the .NET runtime version the game was built for. It runs on the `ghcr.io/caloptreyx/steamcmd:debian` image.

## Capabilities

- Installs the current stable release, the newest release candidate or a fixed version (Vintage Story Version). Reinstall to update or change versions; `data/` (config, worlds, mods) is kept.
- Server name, description, welcome message, password, max players, public listing, whitelist mode, PvP and the world settings are written to `data/serverconfig.json` on every start.
- Console input: server commands are typed in the panel console, e.g. `/help`, `/stats`, `/list clients`, `/autosavenow`, `/op <player>`, `/player <name> whitelist on`, `/announce <message>`.
- Stopping the server sends `/stop`, which saves the world before the server exits.
- Failed installations are reported to Calagopus as failed, with the reason.

## Server Ports

| Port | Default | Protocol  | Required |
|------|---------|-----------|----------|
| Game | 42420   | TCP + UDP | yes (primary allocation) |

## Configuration

`data/serverconfig.json` is generated by the server itself during installation, so it matches the installed version. The panel writes its settings into it on every start; everything else (world configuration such as world size, climate, creature hostility, ...) is edited in that file while the server is stopped, or in game with `/worldconfig`.

Save Name selects the world file `data/Saves/<Save Name>.vcdbs`; a new world is created when it does not exist. World Name, World Seed and Play Style only apply when a new world is created. Whitelist Mode Default means whitelisted players only on dedicated servers: add players with `/player <name> whitelist on`, or set Whitelist Mode to Off.

Since 1.20 servers are not listed publicly by default; turn Public on to list the server.

## Admins

Give a player admin rights from the console with `/op <player>`.

## Saves

Worlds are stored in `data/Saves/`. The server autosaves periodically, on `/autosavenow` and when it is stopped from the panel. Logs are written to `data/Logs/`, mods go in `data/Mods/`. To use an existing world, stop the server, upload the `.vcdbs` file to `data/Saves/` and set Save Name to its name without `.vcdbs`.

## Requirements

About 1-1.2 GB of memory with a new standard world and no players; plan for 4 GB, more with players and a large explored area. The installation (version 1.22.7 with .NET) takes about 400 MB of disk; a new world about 12 MB.

## Sample ignore file for backups

Saved as `.pteroignore` in the server root, this limits backups to the server data:

```
# Ignore all
*
# Except the Vintage Story config, worlds, player data and mods
!data/
```
